# مدونة هندسية بسيطة

مشروع تعليمي لأدهم مؤيد هاشم، مبني على الكود الحالي بدون إضافة مكتبات أو إطار عمل.

## التقنيات

HTML.

## ما الذي يقدّمه؟

استخدام العناصر الدلالية مثل header وnav وmain وarticle وaside وfooter، مع فيديو مضمّن.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `Assignment3/index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `Assignment3/index.html`

## حدود المشروع

عرض الفيديو يحتاج اتصالًا بالإنترنت.

## مراجعة سريعة

جرّب الصفحة على شاشة هاتف، وتنقّل بلوحة المفاتيح، وتحقق من ظهور الصور وعمل الروابط. لا يحتاج المشروع تثبيت حزم.
